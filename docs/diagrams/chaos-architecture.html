Chaos, as the server sees it

Plaintext and private keys stay on the device. The operator surface routes ciphertext through one durable path. Anything else stops at the boundary.

THE INVARIANT

Server is not in the plaintext path

Each send wraps one AES-256-GCM envelope per destination device. The API stores ciphertext, membership, and public pre-key bundles. Private identity keys never leave the machine.

One transaction, then the log

  • Message + envelopes + outbox commit together
  • Kafka publishes only after commit
  • No in-process “just notify” fallback
  • Reconnect is cursor + eventId, not hope

What still leaks

  • Who talks to whom
  • Device count and timing
  • Ciphertext size
  • Call signaling, not media
